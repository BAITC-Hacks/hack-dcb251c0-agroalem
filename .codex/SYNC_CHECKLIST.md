# Sync checklist

Before work:
- [ ] correct repository
- [ ] fetch completed
- [ ] expected role branch
- [ ] working tree status understood
- [ ] HEAD/upstream ahead-behind understood
- [ ] recent main commits reviewed
- [ ] recent Tim commits reviewed
- [ ] recent Danil commits reviewed
- [ ] PROJECT_TRUTH read
- [ ] integration contract read
- [ ] both state files read
- [ ] incoming handoff read
- [ ] role prompt read

Before push:
- [ ] real evidence/tests run
- [ ] own state updated
- [ ] outgoing handoff updated if needed
- [ ] contract updated if needed
- [ ] only target files staged
- [ ] staged diff reviewed
- [ ] atomic commit message
- [ ] push result verified
