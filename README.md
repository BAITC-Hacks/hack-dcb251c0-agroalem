# Voice Router: Saqta Insurance / HackAlem

Демонстрационный контакт-центр для кейса **Voice Router**. Клиент пишет или произносит обращение; LLM выбирает сценарий из исходного каталога, учитывает контекст, а сервер возвращает ответ и объяснимую трассировку. Компания Saqta Insurance и данные клиентов вымышлены.

**Текущая демонстрационная сборка: `tim/backend`.** В ней есть Python-сервер и встроенная страница жюри. `danil/frontend` содержит отдельный React-интерфейс по референсам. Это две рабочие ветки, а не заявление о завершённом релизе в `main`.

## Что было заданием хакатона

По [зафиксированным требованиям кейса](docs/HACKATHON_REQUIREMENTS.md), нужно создать **голосового ИИ-бота с веб-интерфейсом**, где содержательное решение о сценарии принимает LLM вместо классического intent-классификатора. Обязательны живая речь, голосовой ответ, русский/казахский и смешанный ввод, контекст до 10 ходов и панель supervisor после каждой реплики: транскрипт, сценарий, краткое объяснение, альтернативы и длительности стадий.

Текстовый ввод является дополнительным каналом. **Один текстовый чат не закрывает обязательный голосовой кейс.** Главный проверяемый результат: корректная маршрутизация естественных обращений, включая смену темы и близкие сценарии, а не только распознавание и озвучка речи.

Исходные данные: [starter-kit/README.ru.md](starter-kit/README.ru.md), 40 бизнес-сценариев, 3 системных намерения, база знаний, mock backend, примеры диалогов и 104 размеченные реплики. Жюри использует отдельные скрытые реплики. Исходные labels не изменяются для улучшения метрик.

## Что готово и что ещё не подтверждено

Срез состояния: **23 сентября 2026 года**. Реализация и успешная живая проверка обозначены отдельно.

| Требование / компонент | Что реализовано | Подтверждение и оставшаяся работа |
| --- | --- | --- |
| LLM выбирает сценарий | Каталог, `not_this_if`, примеры и контекст передаются в OpenAI; structured output проверяется. | Код и тесты есть. Полный живой baseline на 104 репликах пока не опубликован. |
| Текстовый диалог | `/v1/turn/text`, история, policy и отдельный ответ по исходной базе знаний. | Данил подтвердил живой текстовый путь на старом backend `ce761bd`. Новый слой ответа требует повторной живой проверки. |
| Голосовой веб-путь | Встроенная страница: микрофон/файл → OpenAI STT → текстовый путь → OpenAI TTS → MP3. | Реализован и проверен контрактными тестами. Живой сквозной голосовой прогон новой сборки ещё не подтверждён. |
| RU / KK / mixed | Языковые поля, промпты, текст и история предусмотрены. | Нет опубликованной систематической оценки маршрутизации и качества речи по всем трём группам. |
| Контекст | До 10 последних ходов, параметры, последовательная обработка сессии и откат неуспешного текстового хода. | Память процесса, не постоянная БД. Полный executor со стеком прерванных сценариев не заявляется готовым. |
| Supervisor trace | Транскрипт, сценарии, confidence, reason, альтернативы, slots, actions, флаги и измеряемые длительности. | Тесты есть; у Данила есть живое подтверждение текстового trace на старой версии backend. |
| Uncertainty / handoff | Пороги 0.75/0.45, уточнение, два низких результата подряд, состояние handoff. | Реального соединения с человеком нет. Интерфейс не должен сообщать об успешном соединении. |
| Необратимые действия | Отображается требование подтверждения из сценария; операции не исполняются. | Полный workflow подтверждения и исполнения не реализован. `trace.actions=[]`. |
| Интерфейс Данила | React, история, состояния ошибок, trace каждой реплики, адаптивная вёрстка, lockfile и тесты. | Текстовый интерфейс проверен Данилом. Аудиотранспорт добавлен; подключение его к React-кнопкам и живой прогон остаются задачей frontend. |
| Один запуск и README | `run_mvp.py`, встроенная страница и настоящие команды ниже. | Свежий клон и полная приёмка текущей сборки ещё должны быть проверены. |

**Итог:** это реализованный демонстрационный MVP маршрутизации и read-only консультации с текстовым и голосовым кодовым путём. Это **не утверждение, что все требования хакатона уже приняты**, и не полноценная страховая операционная система.

## Запуск для жюри

Нужны **Python 3.10+**, полный клон, доступ к приватному репозиторию и интернет для установки пакетов и запросов OpenAI. Для встроенной страницы React/Node.js не требуются.

### Windows / PowerShell: новый клон

```powershell
git clone --branch tim/backend https://github.com/BAITC-Hacks/hack-dcb251c0-agroalem.git voice-router
cd voice-router
if (-not (Test-Path .env.local)) { Copy-Item .env.example .env.local }
notepad .env.local
```

В локальном `.env.local` задайте `OPENAI_API_KEY`. Не публикуйте файл и не передавайте ключ браузеру. Существующий файл не перезаписывается. В уже используемой рабочей папке сначала проверьте `git status`; не удаляйте несохранённые изменения ради переключения ветки.

Запуск одной командой:

```powershell
py run_mvp.py
```

Скрипт создаёт `.venv`, устанавливает `backend/requirements.txt` и запускает сервер. Страница: **http://127.0.0.1:8000**, API-документация: **http://127.0.0.1:8000/docs**. Остановка: `Ctrl+C`. Скрипт не переключает ветки, не коммитит файлы и не выводит ключи.

### Linux / macOS

```bash
test -f .env.local || cp .env.example .env.local
# Отредактируйте локальный .env.local, затем:
python3 run_mvp.py
```

Повторный запуск без установки пакетов, с уже подготовленным интерпретатором:

```powershell
.venv\Scripts\python.exe run_mvp.py --no-install
```

На Linux/macOS: `.venv/bin/python run_mvp.py --no-install`. Это пропуск установки, **не offline-режим моделей**. Сервер слушает только loopback; публичная производственная эксплуатация не предусмотрена.

## Как пользоваться и что показывать

**Текст:** напишите вопрос и нажмите «Отправить текст». Ответ появится в истории. Trace принадлежит выбранной реплике; предыдущие доступны через «Посмотреть trace». Ошибка нового запроса не получает старый успешный trace.

**Голос:** «Записать голос» → разрешение микрофона → «Остановить и отправить». На встроенной странице запись ограничена 60 секундами. Ответ можно прослушать в плеере; голос обозначен как созданный ИИ.

**Файл:** WebM, MP4/M4A, MP3 или WAV, до 20 MiB. Пустой/неподдерживаемый файл отклоняется. **Озвучка текста:** «Озвучить ответ ИИ» повторяет только TTS, не маршрутизацию. Ошибка озвучки сохраняет текст и trace.

**Новая сессия:** новый ID и очищенная браузерная история. Перезапуск сервера сбрасывает его память. **Отмена:** прекращает ожидание в браузере, но не гарантирует остановку уже принятого сервером или OpenAI запроса. Автоповтора нет.

Ручной сценарий демонстрации, не встроенный набор ответов:

1. «Подскажите адрес офиса в Караганде», затем «А в субботу он работает?» Проверить выбор сценария, ответ по базе и использование истории.
2. Проверить казахский и смешанный текст: «Алматыдағы кеңсенің мекенжайын айтыңызшы», «Полис бойынша бір сұрақ: как получить копию?»
3. Попросить оператора: проверить handoff без заявления о фактическом соединении.
4. Произнести новую реплику, сравнить транскрипт, trace и озвучку. Отказать в доступе к микрофону: текст должен остаться доступен.
5. Проверить ошибку API: она не должна выглядеть как успешная маршрутизация.

Ожидаемую корректность этих примеров необходимо подтвердить живым прогоном. Записанный ролик и тестовые fixtures не подменяют живую демонстрацию.

## OpenAI и HackAlem Sandbox

По инструкции организаторов, переданной команде, **HackAlem Sandbox** выбирается как workspace при работе с ChatGPT/Codex. Для приложения отдельно принимается приглашение в API Platform, выбираются организация хакатона и проект команды, после чего создаётся проектный API-ключ. Доступ и лимиты конкретного проекта здесь не проверены.

Workspace ChatGPT и API-проект имеют разные механизмы доступа и учёта. Вход в Codex через ChatGPT не подставляет ключ в наш backend. Для MVP нужен именно серверный `OPENAI_API_KEY` разрешённого проекта.

**Sandbox из приглашения не является установкой моделей на компьютер и не включает offline-инференс.** Текущий MVP отправляет запросы на `https://api.openai.com/v1/`. Без сети можно редактировать код и запускать подготовленные тесты с fixtures; живые LLM/STT/TTS не работают. Полностью автономная версия потребовала бы отдельных локальных моделей и интеграции, которой в этой сборке нет. Не выдавайте тестовую подстановку за работу модели.

| Переменная | Значение по умолчанию / назначение |
| --- | --- |
| `OPENAI_API_KEY` | Локальный серверный секрет. |
| `OPENAI_ROUTER_MODEL` | `gpt-4.1-mini` |
| `OPENAI_RESPONSE_MODEL` | `gpt-4.1-mini` |
| `OPENAI_STT_MODEL` | `gpt-4o-mini-transcribe` |
| `OPENAI_TTS_MODEL` | `gpt-4o-mini-tts` |
| `OPENAI_TTS_VOICE` | `coral` |
| `OPENAI_TIMEOUT_SECONDS` | `45` на запрос к провайдеру. |
| `CORS_ORIGINS` | Локальные origin Vite на порту 5173. |

Переменные процесса имеют приоритет над `.env.local`, затем `.env`. Старое явно заданное имя модели имеет приоритет над default: проверьте его вручную. Это конфигурация, не доказательство качества моделей на нашем датасете. Runtime использует REST через HTTPX; переход на NVIDIA не реализован и данным README не включается.

**Секреты:** опубликованный или отправленный в общий чат ключ нужно отозвать и заменить. Ни секреты, ни их копии, ни скриншоты не коммитятся. Каждый участник использует собственные разрешённые учётные данные; для общего сервера ключ настраивается серверным владельцем. `.env.example` содержит только названия и безопасные настройки.

## API и интерфейс Данила

| Метод | Endpoint | Формат / назначение |
| --- | --- | --- |
| GET | `/health` | Каталог и наличие настройки; без проверки ключа запросом OpenAI. |
| GET | `/v1/config` | Публичные модели, пути и форматы; без секретов. |
| POST | `/v1/turn/text` | JSON `{ "session_id": "demo-1", "text": "Вопрос" }`. |
| POST | `/v1/audio/transcriptions` | Multipart `file`; `{text, latency_ms}`; без хода диалога. |
| POST | `/v1/audio/speech` | JSON `{text}` до 2000 символов; MP3. |
| POST | `/v1/turn/audio` | Multipart `session_id`, `file`, `include_audio`; текстовый ход и необязательная озвучка. |

Голосовой ответ добавляет `assistant_audio: {mime_type, base64, ai_generated}` или `null` и `audio_error`. Если TTS упал после успешного текстового хода, возвращаются HTTP 200, текст, trace и `audio_error`; повторяется только озвучка.

Ошибки: 413 размер; 415 формат; 422 ввод; 429 локальная ёмкость сессий; 503 ключ/доступ; 502 ответ/соединение/квота провайдера; 504 тайм-аут. Сырые payloads провайдера и ключи в сообщениях не раскрываются.

`confidence` является оценкой модели, не откалиброванной вероятностью правильности. `needs_clarification` и `handoff` показывают решение policy. `tts_first_audio=null`: пакетная генерация не измеряет первый услышанный пользователем звук; её полная длительность отдельно записывается в `tts`. Неизмеренное не заменяется нулями.

Данил сохраняет владение дизайном и React-вёрсткой. Текущий контракт читается из `origin/tim/backend:.codex/INTEGRATION_CONTRACT.md`, а не из устаревшей копии в его ветке. Аудиоклиент: `frontend/src/shared/turn-client/audio.ts`; инструкции: `frontend/AUDIO_HANDOFF.md` в `danil/frontend`. Сливать весь backend ради чтения контракта не требуется.

## Проверки до сдачи

```powershell
py run_mvp.py --check
.venv\Scripts\python.exe -m backend.scripts.run_baseline
```

Первая команда запускает полный backend pytest. Вторая выполняет 3 live smoke-запроса RU/KK/mixed, 104 prediction-запроса и исходный `starter-kit/evaluate.py`. Вызовы расходуют API-квоту. В `baseline-report.txt` сохраняются модель, Git SHA, SHA-256 датасета и результат evaluator. При сбое остаётся partial checkpoint; незавершённый прогон не считается baseline.

В `.codex/TIM_STATE.md` нужно записать реальные primary accuracy, full match, multi-intent recall, разбивки по языкам/типам и ошибки. **Только после baseline начинается tuning.** Результаты 104 живых запросов здесь не заполнены.

Для frontend на его ветке: `cd frontend`, `pnpm install --frozen-lockfile`, `pnpm check` и предусмотренные в `frontend/README.md` браузерные проверки. Затем проверить frontend против НОВОГО backend, а не переносить статус со старого коммита.

Перед сдачей остаются: полный pytest новой сборки, baseline, живой голосовой прогон RU/KK/mixed, проверка актуального React-интерфейса, свежий клон/запуск и разрешение конфликтов интеграции. PR #2 и #3 на момент этого среза остаются draft; merge не заявляется выполненным.

## Ограничения и устранение ошибок

Нет выпуска/изменения/расторжения полиса, регистрации убытка, SMS, записи к врачу, реального оператора и полного confirmation executor. `requires_confirmation` обозначает требование, не выполненную операцию. Нет постоянной БД, авторизации, multi-worker state, потоковой речи или доказанного latency SLA. Grounding-промпт не гарантирует фактическую точность каждого ответа.

Дата среза синтетического датасета: **2026-10-01**. Она применяется к относительным датам в данных, а не заменяет календарную дату. Условия Saqta не являются реальными страховыми или юридическими рекомендациями. Для тестов используйте только синтетические данные.

- **503/502/504:** проверьте API-проект, ключ, доступ к модели, квоту и сеть; перезапустите процесс после изменения окружения. Приложение не выбирает другую модель незаметно.
- **Нет микрофона:** используйте localhost или HTTPS, проверьте разрешение браузера; остаются текст и загрузка файла.
- **Нет starter-kit:** нужен полный клон `tim/backend`. Отдельный README или архив изменённых файлов не является приложением.
- **UI Данила меняется:** для проверки функциональности есть независимая встроенная страница `/`.
- **Нет интернета:** Sandbox-workspace и `--no-install` не включают автономную маршрутизацию.
