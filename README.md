# Voice Router: текстовый и голосовой демонстрационный MVP

Веб-демо контакт-центра вымышленной Saqta Insurance для HackAlem. Посетитель пишет запрос или записывает голос; сервер выбирает сценарий через LLM, применяет политику уверенности, формирует ответ по исходной базе знаний и показывает трассировку. Распознавание и озвучка используют **тот же серверный ключ OpenAI**.

**Рабочая версия этого этапа находится в `tim/backend`.** Ветка `danil/frontend` содержит отдельно разрабатываемый React-интерфейс. Для запуска страницы жюри React, Node.js и слияние двух веток не нужны: базовая страница уже обслуживается Python-сервером.

## Статус, который важно не перепутать

Код текстового пути, ответа по базе знаний, HTTP-интеграций OpenAI STT/TTS, страницы жюри и аудиоклиента написан. В изолированной среде выполнены **46 серверных контрактных/regression-тестов и 16 тестов аудиоклиента**. Это тесты с контролируемыми ответами провайдера, а не доказательство качества живой модели.

**Живые OpenAI-вызовы и baseline на 104 репликах в этой сессии не выполнены: ключ не был доступен исполняющей среде.** Полная проверка браузер → локальный сервер была заблокирована политикой Chromium (`ERR_BLOCKED_BY_ADMINISTRATOR`), поэтому она не помечена пройденной. Полный pytest всего репозитория и полная React-сборка также не заявляются проверенными этим отчётом. Перед демонстрацией выполните проверки ниже на рабочем компьютере.

## 1. Быстрый запуск для жюри

Нужны Python **3.10+**, доступ к приватному репозиторию и интернет. API OpenAI должен быть доступен вашему ключу; наличие подписки на чат само по себе не проверяется приложением.

### Windows / PowerShell

```powershell
git clone --branch tim/backend https://github.com/BAITC-Hacks/hack-dcb251c0-agroalem.git voice-router
cd voice-router
if (-not (Test-Path .env.local)) { Copy-Item .env.example .env.local }
notepad .env.local
```

В `.env.local` заполните только локальное значение `OPENAI_API_KEY`. Никогда не отправляйте этот файл в Git и не переносите ключ в настройки браузера.

Запуск одной командой:

```powershell
py run_mvp.py
```

Скрипт создаёт локальную `.venv`, устанавливает зависимости из `backend/requirements.txt` и запускает сервер на **http://127.0.0.1:8000**. Откройте этот адрес в браузере. Остановка: `Ctrl+C` в терминале.

### Linux / macOS

```bash
test -f .env.local || cp .env.example .env.local
# Заполните OPENAI_API_KEY в локальном файле.
python3 run_mvp.py
```

Если зависимости уже установлены в активном окружении:

```bash
python run_mvp.py --no-install
```

Первичная установка требует сети. Скрипт не меняет ветки, не делает коммиты и не выводит секреты. Сервер намеренно слушает только loopback: это локальное демо, не защищённый публичный сервис.

## 2. Как пользоваться

**Текст.** Введите вопрос и нажмите «Отправить текст». Ответ появится в истории, а справа будет trace именно выбранной реплики. После ошибки новая реплика не получает trace от предыдущего успешного запроса. Старые трассировки доступны через «Посмотреть trace».

**Голос.** Нажмите «Записать голос», разрешите микрофон, затем «Остановить и отправить». Лимит записи на странице: 60 секунд. Сервер выполняет STT → тот же текстовый путь → TTS. Автовоспроизведение не требуется: используйте аудиоплеер. Голос явно обозначен как созданный ИИ.

**Аудиофайл.** Можно загрузить WebM, MP4/M4A, MP3 или WAV объёмом до 20 MiB. Неподдерживаемый или пустой файл отклоняется до отправки провайдеру. Произвольные названия файлов не используются как пути или команды.

**Озвучка текстового ответа.** Нажмите «Озвучить ответ ИИ» у нужной реплики. Ошибка TTS не удаляет ответ и trace. Повтор этой кнопки повторяет только озвучку, а не маршрутизацию.

**Новая сессия.** Кнопка создаёт новый идентификатор и очищает локальную историю. Сервер хранит до 10 последних ходов каждой сессии в памяти процесса. Перезапуск сервера сбрасывает память; неактивные сессии удаляются при обслуживании последующих запросов.

**Отмена.** Отмена прекращает ожидание в браузере. Она не гарантирует остановку уже принятого сервером или OpenAI запроса. Автоматического повтора нет, в том числе чтобы не создавать незаметные повторные платные вызовы.

## 3. Что показать жюри

1. Начать с информационного вопроса, например: «Подскажите адрес офиса в Караганде». Проверить сценарий, rationale и альтернативы в trace.
2. Задать уточнение без повторения контекста: «А в субботу он работает?» История пользователя и ассистента передаётся в следующий ход.
3. Проверить казахский и смешанный ввод, например: «Алматыдағы кеңсенің мекенжайын айтыңызшы» и «Полис бойынша бір сұрақ: как получить копию?»
4. Попросить оператора. Интерфейс должен показать handoff, но не заявить о фактическом подключении человека.
5. Записать голос, проверить транскрипт и прослушать ответ. Отдельно проверить отказ в разрешении микрофона: текстовый ввод должен оставаться доступным.

Это примеры ручной проверки, не встроенные правила распознавания. Совпадение с ожидаемым сценарием необходимо проверить живым вызовом; оно здесь не заявляется измеренным.

## 4. Что делает сервер

| Часть | Поведение |
| --- | --- |
| Каталог | Загружает исходные 40 бизнес-сценариев и 3 системных intent из `starter-kit/scenarios.json`. |
| Маршрутизация | Отправляет каталог, `not_this_if`, примеры и историю в OpenAI Responses с JSON Schema. Keyword-классификатора в production-пути нет. |
| Проверка результата | Отклоняет неизвестные scenario ID, повторные имена slots и невалидный structured output. |
| Уверенность | Использует существующие пороги 0.75 и 0.45; средняя уверенность сбрасывает streak низкой уверенности. Два низких результата подряд ведут к handoff. |
| Ответ | Для принятого бизнес-сценария выполняет отдельный запрос к OpenAI с исходной `knowledge_base.json`, текущим вопросом, историей и собранными значениями. |
| Контекст | Сохраняет пользователя, ответ ассистента и значения параметров. Изменения сессии фиксируются только после успешного текстового хода. |
| Аудио | Использует официальные `/v1/audio/transcriptions` и `/v1/audio/speech` OpenAI. Другие AI-провайдеры не вызываются. |
| Trace | Возвращает транскрипт, язык, сценарии, confidence, краткое объяснение, альтернативы, параметры, флаги и измеренные длительности стадий. |

`confidence` — оценка модели, **не измеренная вероятность правильности**. Калибровка ещё не выполнена. В trace сохраняются кандидаты маршрутизатора; флаги `needs_clarification` и `handoff` показывают решение policy и должны учитываться интерфейсом.

`tts_first_audio` остаётся `null`: пакетный режим не измеряет момент первого услышанного пользователем звука. Полная серверная генерация озвучки записывается отдельно в `tts`. Неизмеренные величины не заменяются нулями.

## 5. Границы MVP

Это **консультационное read-only демо с маршрутизацией**, а не законченная страховая операционная система. Реальный выпуск/изменение/расторжение полиса, регистрация убытка, запись к врачу, отправка SMS и подключение оператора не реализованы. `trace.actions` поэтому остаётся пустым. `requires_confirmation` — требование из каталога, а не доказательство выполненной операции или полноценного workflow подтверждения.

Ответ по базе знаний генерирует LLM. Наличие grounding-промпта и структурной проверки само по себе не гарантирует фактическую точность каждого ответа. Для этого требуются живые проверки и отдельная оценка ответов.

Нет пользовательской авторизации, постоянной БД, multi-worker хранения сессий, промышленного лимитирования расходов, потоковой речи и доказанного latency SLA. Запускайте один серверный процесс, локально. Качество RU/KK/mixed STT/TTS не измерено этим набором тестов.

Данные Saqta синтетические. Дата среза **2026-10-01** применяется к относительным датам внутри датасета; это не утверждение о текущей календарной дате и не реальные страховые или юридические условия.

## 6. Настройки OpenAI

| Переменная | По умолчанию |
| --- | --- |
| `OPENAI_API_KEY` | Обязательный серверный секрет. |
| `OPENAI_ROUTER_MODEL` | `gpt-4.1-mini` |
| `OPENAI_RESPONSE_MODEL` | `gpt-4.1-mini` |
| `OPENAI_STT_MODEL` | `gpt-4o-mini-transcribe` |
| `OPENAI_TTS_MODEL` | `gpt-4o-mini-tts` |
| `OPENAI_TTS_VOICE` | `coral` |
| `OPENAI_TIMEOUT_SECONDS` | `45` на запрос к провайдеру. |
| `CORS_ORIGINS` | Два локальных origin Vite на порту 5173. |

Ранее заданный `gpt-5.6-luna` не используется как неподтверждённый default. Здесь выбран документированный `gpt-4.1-mini`, но никакого вывода о его качестве на этом датасете до baseline не делается. Явно заданный `OPENAI_ROUTER_MODEL` имеет приоритет; исправьте старое значение в своём окружении при необходимости.

Клиент использует прямой REST OpenAI через HTTPX и фиксированный origin `https://api.openai.com/v1/`. OpenAI SDK для этого пути не требуется. Переменные процесса имеют приоритет над `.env.local`, затем читается `.env`. В браузер отправляется только адрес нашего backend, никогда provider key.

## 7. API для интерфейса Данила

Интерактивная документация: **http://127.0.0.1:8000/docs**.

| Метод | Endpoint | Назначение |
| --- | --- | --- |
| GET | `/health` | Каталог и наличие настройки ключа. Не вызывает OpenAI и не подтверждает работоспособность ключа. |
| GET | `/v1/config` | Публичные модели, пути и допустимые форматы. Секретов нет. |
| POST | `/v1/turn/text` | JSON `{ "session_id": "demo-1", "text": "Вопрос" }`. |
| POST | `/v1/audio/transcriptions` | Multipart `file`; JSON `{text, latency_ms}`. Не создаёт ход диалога. |
| POST | `/v1/audio/speech` | JSON `{text}` до 2000 символов; MP3 в теле ответа. |
| POST | `/v1/turn/audio` | Multipart `session_id`, `file`, `include_audio`; полный ход и необязательная озвучка. |

Голосовой результат сохраняет форму текстового и добавляет `assistant_audio: {mime_type, base64, ai_generated}` или `null`, а также `audio_error`. После сбоя TTS уже успешный текстовый ход возвращается с HTTP 200 и `audio_error`: не нужно повторно отправлять всю реплику.

Ошибки: 413 — размер; 415 — формат записи; 422 — ввод; 429 — локальная ёмкость занятых сессий; 503 — ключ/доступ к OpenAI; 502 — ответ/соединение/квота провайдера; 504 — тайм-аут. Тексты ошибок не содержат сырые provider payloads.

В `danil/frontend` добавлен `frontend/src/shared/turn-client/audio.ts`: `AudioApiClient.transcribe`, `.synthesize`, `.submitVoice`. Поле `trace` из voice envelope нужно проверить существующим `turnResultSchema` перед отображением. Дизайн, вёрстка, React-компоненты и работа по референсам остаются у Данила. Для изучения контракта не требуется сливать весь backend в его ветку.

## 8. Проверки и реальный baseline

Полная проверка backend на рабочем клоне:

```powershell
py run_mvp.py --check
```

После этого, из установленного окружения:

```powershell
.venv\Scripts\python.exe -m backend.scripts.run_baseline
```

Runner делает три живых smoke-запроса RU/KK/mixed, затем 104 prediction-запроса и запускает исходный `starter-kit/evaluate.py`. Это платные API-вызовы. Он сохраняет model ID, Git SHA, SHA-256 датасета, прогресс и результат evaluator в `baseline-report.txt`. При сбое остаётся partial checkpoint, а отчёт не получает статус завершённого baseline.

Сохраните фактические primary accuracy, full match, multi-intent recall, разбивку по языкам/типам и ошибки в `.codex/TIM_STATE.md`. **Только после измеренного baseline начинается tuning.** В этой поставке значения метрик не выдуманы и не заполнены.

Отдельные проверенные в этой сессии тесты:

```bash
python -m pytest backend/tests/test_mvp_runtime.py -q
# 46 passed; unit fixtures, не live OpenAI.

cd frontend
node --test scripts/audio.check.mjs
# 16 passed при наличии TypeScript; не полный pnpm check.
```

## 9. Если что-то не работает

**503.** Проверьте локальный ключ, доступ API к выбранной модели и перезапустите процесс после изменения окружения. Не вставляйте ключ в браузер.

**502 / квота.** Проверьте API-квоту и выбранную модель. Приложение не подменяет ошибку вымышленным результатом и не выбирает другую модель незаметно.

**Микрофон отсутствует.** Используйте localhost или HTTPS, проверьте разрешение браузера. Текст и загрузка файла остаются альтернативами. Микрофон/кодеки конкретного браузера необходимо проверить перед выступлением.

**Не найдены starter-kit файлы.** Запускайте полный клон `tim/backend`. Архив только изменённых файлов или отдельный скачанный README не является самостоятельным приложением.

**UI по референсам ещё меняется.** Для показа функциональности используйте встроенную страницу `/`; она независима от React-сборки Данила.
